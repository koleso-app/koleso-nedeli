# Колесо недели

Личный планировщик свободного времени: таймер блоков с подсказкой «что дальше», рабочий режим,
темы дней, ежедневные мини-шаги, колесо недели и бюджет часов.
Есть программа для Windows и версия для телефона, которая открывается в браузере и ставится на главный экран.

## Где лежат данные

- **Windows:** `%APPDATA%\Колесо недели\koleso-data.json`; ежедневные копии за 14 дней — в папке `backups`.
  Ключи синхронизации — в `sync.bin`, зашифрованы средствами Windows (DPAPI).
  Если файл не удаётся прочитать (например, его держит антивирус), программа ничего не записывает и предлагает повторить.
- **Телефон:** в хранилище браузера на самом телефоне.
- **Синхронизация (по желанию):** один файл `koleso.enc.json` в вашем **приватном** репозитории GitHub.
  Он зашифрован AES-256-GCM ключом из вашего пароля (PBKDF2-SHA-256, 600 000 итераций). Пароль никуда
  не отправляется; без него файл не прочитать ни GitHub, ни кому-либо ещё. Приложение откажется
  синхронизироваться с публичным репозиторием.

Код приложения в этом репозитории не содержит ваших данных.

## Разработка

```
npm install
npm start          # Windows-программа из исходников
npm run web        # версия для телефона на http://127.0.0.1:5178
npm test           # тесты шифрования и слияния данных
npm run dist       # установщик в dist/
```

`npm run assets` пересоздаёт значки (`scripts/make-icons.js`) и шрифты (`scripts/copy-fonts.js`).
Проверка без своих данных: `KOLESO_SMOKE=<папка> npx electron .` — скриншоты и отчёт в папку.

Версия для телефона — это папка `app/`; при пуше в `main` её публикует GitHub Pages
(`.github/workflows/pages.yml`). Адрес: https://koleso-app.github.io/koleso-nedeli/
